# app-sessions

Claude 데스크톱 앱(Code 탭) 세션과 터미널 CLI 세션을 **서로 옮겨 이어가기** 위한 명령과 스킬입니다.

- **앱 → CLI:** 앱 사이드바의 세션 ID(`local_…`)와 CLI 가 쓰는 세션 ID 는 다릅니다. 앱의 세션 정보
  파일에서 둘의 대응을 읽어, 제목으로 세션을 찾고 `claude --resume` 으로 이어가게 해 줍니다.
  앱에서 **보관(archive)한 세션도 포함**됩니다.
- **CLI → 앱:** 터미널에서 시작한 세션은 앱 사이드바에 자동으로 뜨지 않습니다. 아직 앱에 없는
  CLI 세션을 찾아 데스크톱 앱에서 엽니다. 터미널을 다시 열어 `/desktop` 을 입력할 필요가 없습니다.

macOS 전용입니다 (앱 세션 정보 위치: `~/Library/Application Support/Claude/claude-code-sessions/`).

## 설치

저장소 루트에서 `sh setup.sh` 를 실행하면 두 가지가 연결됩니다.

- 명령: `~/.local/bin/app-sessions` → 이 폴더의 `app-sessions`
- 스킬: `~/.claude/skills/app-sessions` → 이 폴더

## 명령 사용법

**앱 세션 → CLI**

| 명령 | 동작 |
|---|---|
| `app-sessions` | 앱 세션 전체 (최근 활동 순): 날짜, 제목, 폴더, CLI 세션 ID |
| `app-sessions 검색어` | 제목·폴더·ID 에 검색어가 들어간 세션만 |
| `app-sessions -r 검색어` | 찾은 세션의 폴더로 이동해 `claude --resume` 실행. 여러 개면 번호 선택 |
| `app-sessions -a` | 보관된 세션만 |

**CLI 세션 → 앱**

| 명령 | 동작 |
|---|---|
| `app-sessions --cli` | 아직 앱에 없는 CLI 세션 (최근 대화 순). 제목은 AI 제목, 없으면 첫 메시지 |
| `app-sessions --cli 검색어` | 제목·첫 메시지·폴더·ID 에 검색어가 들어간 세션만 |
| `app-sessions -o 검색어` | 찾은 CLI 세션을 데스크톱 앱에서 열기. 여러 개면 번호 선택 |

`--json` 을 붙이면 JSON 으로 출력합니다 (스킬이 사용).

표시: `[보관]` 보관된 세션, `[기록 없음]` CLI 기록 파일이 지워져 이어갈 수 없는 세션,
`[실행 중]` 지금 프로세스가 살아 있는 세션.
`[다른 계정 xxxxxxxx]` 지금 CLI 에 로그인한 계정이 아닌 다른 계정의 앱 세션 (앞 8자리는 계정 ID).
앱 사이드바에는 안 보일 수 있지만 CLI 로는 이어갈 수 있습니다.

**CLI → 앱 동작 원리:** CLI 의 `/desktop` 명령은 기록을 저장한 뒤
`claude://resume?session=<CLI 세션 ID>` 링크를 여는 것이 전부입니다 (Claude Code v2.1.282 코드로 확인).
`-o` 는 CLI 가 꺼진 상태에서 이 링크를 직접 엽니다. 불러온 세션의 앱 ID 는 `local_<CLI 세션 ID>` 가 됩니다.

## 스킬

Claude 에게 "앱 세션 찾아줘", "어제 하던 보고서 세션 터미널에서 이어가게 해줘",
"터미널에서 하던 세션 앱에서 열어줘" 처럼 말하면 스킬이 이 명령을 실행해 결과를 표로 정리합니다.
CLI 로 이어가기는 대화형이라 사용자가 직접 실행하고, 앱에서 열기는 확인을 받은 뒤 Claude 가 실행합니다.

## 주의

- 앱에서 같은 세션이 열려 있으면 먼저 닫습니다. 두 곳에서 동시에 쓰면 기록이 엉킬 수 있습니다.
- `-o` 는 터미널에서 실행 중인 세션은 거절합니다. 그 터미널에서 `/exit` 로 끝내거나 `/desktop` 을 입력합니다.
- 앱 세션을 CLI 에서 이어가면 그 기록은 CLI 쪽 보관기간(`cleanupPeriodDays`, 기본 30일)을
  따르게 됩니다. `setup.sh` 는 이 값이 없으면 36500(약 100년)으로 설정합니다.
- 앱 세션 정보 파일의 구조와 `claude://resume` 링크는 공식 문서에 없는 내부 동작입니다. 앱이나
  Claude Code 업데이트로 바뀌면 이 명령을 고쳐야 할 수 있습니다.
