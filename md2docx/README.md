# md2docx

마크다운 파일을 Word(.docx) 문서로 변환합니다. 한국어 실무 문서를 염두에 두고 만들었습니다.

## 설치

```bash
pip install python-docx
```

macOS Homebrew Python이면 `--break-system-packages`를 붙입니다.

## 사용법

```bash
python3 md2docx.py 문서.md
python3 md2docx.py 문서.md 결과.docx
python3 md2docx.py 문서.md --font "KoPubBatang Medium" --size 11
python3 md2docx.py 문서.md --subtitle "작성 2026-09-15" --wide-cols 6
python3 md2docx.py 문서.md --no-toc
```

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--font` | 맑은 고딕 | 본문 글꼴 |
| `--mono` | D2Coding | 인라인 코드 글꼴 |
| `--size` | 10 | 본문 크기(pt). 제목 크기는 여기에 맞춰 커짐 |
| `--wide-cols` | 7 | 이 열 수 이상인 표는 가로 페이지에 배치 |
| `--subtitle` | 없음 | 첫 제목 아래에 회색으로 넣을 한 줄 |
| `--no-toc` | 끔 | 목차 필드를 넣지 않음 |

## 왜 만들었나

pandoc은 설치 용량이 150MB에 이르고, 한글 PDF를 뽑으려면 LaTeX 조판 엔진까지 필요합니다.
표가 많은 국문 실무 문서 하나를 Word로 바꾸자고 치르기에는 비용이 큽니다.
이 도구는 python-docx 하나만 있으면 동작하고, 서식을 문단 단위로 지정하므로
표 폭이나 글꼴 같은 세부를 원하는 대로 다룰 수 있습니다.

## 특징

**열이 많은 표는 가로 페이지로 보냅니다.** 실무 문서의 일정표나 서류 목록은 열이 일고여덟 개씩 되는데
A4 세로에 넣으면 글자가 뭉개집니다. 기준 열 수를 넘는 표를 만나면 앞뒤로 가로 방향 구역을 자동으로 넣고,
표가 끝나면 다시 세로로 돌아옵니다.

**확대 비율을 100%로 고정합니다.** python-docx가 만드는 문서는 기본이 `bestFit`이라
창 크기에 따라 글자가 커졌다 작아졌다 합니다. 이 설정을 끕니다.

**한글 글꼴을 제대로 지정합니다.** `w:eastAsia` 속성까지 함께 설정해야 한글이 지정한 글꼴로 나옵니다.

## 지원 문법

제목(`#`~`####`), 표, 목록(`-` `*` `1.`), 인용(`>`), 굵게(`**`), 인라인 코드(`` ` ``),
링크(`[텍스트](주소)`), 구분선(`---`)을 처리합니다.

링크는 텍스트만 남기고 파란색으로 표시합니다. 실제 하이퍼링크는 걸지 않습니다.
본문에 그대로 쓰인 URL은 줄을 넘치지 않도록 작은 글자로 줄입니다.

## 만들어지는 문서

A4 세로, 좌우 여백 1.8cm, 줄간격 1.3입니다.
맨 앞에 목차 필드가 들어가는데, Word에서 그 자리를 오른쪽 클릭하고 필드 업데이트를 누르면 채워집니다.

## 한계

- 이미지, 각주, 중첩 표는 처리하지 않습니다
- 표 안의 줄바꿈(`<br>`)은 지원하지 않습니다
- 목록 안의 표는 표로 인식하지 않습니다
